Network

DNS over HTTPS

More

Used for everything the browser fetches: its pages, their pictures and videos, downloads and filter lists. While it’s on there’s no falling back to this server’s DNS: a local or private name resolves only from Local DNS records or this server’s /etc/hosts; otherwise use its address. Private network access (WEB_GO_PRIVATE) doesn’t change that.

Local DNS records

Names reached at the addresses you give (A and AAAA records).

    More

    A name is looked up here first; then in this server’s /etc/hosts; then by DNS over HTTPS, or this server’s own DNS. A name listed is only ever at its addresses. Private network addresses need private network access (WEB_GO_PRIVATE); this server’s own are never reached.

    Filter lists

      Unsaved

      Your own rules, one a line, as filter lists write them.

        More

        ||ads.example^, or a site’s name alone, blocks it; /banner/*$image blocks pictures at such addresses; ##.ad hides what has that class; @@ before a rule makes it an exception; ! … is a note. Sites they name are blocked wherever ad blocking is.

        Backup

        Export and import

        The settings on this page in one file: search engine, DNS over HTTPS, local DNS records, ad blocking, its lists and your filters. Site controls’ settings aren’t in it.

        Paste hosts lines

        One a line, as /etc/hosts writes them: an address, then its names (192.168.1.10 nas.home.arpa nas). # starts a note. They’re added to the records.
